Art-direction briefs:

- **Ownership:** black background, fine off-white/cyan isometric linework;
  three separately owned work parcels, each with a person marker; one cyan
  highlighted parcel. No labels, interface chrome, or automatic reassignment.
- **Coordination:** matching palette and linework; two agent markers connected
  through an envelope on a durable ledger stack. No runtime requirement,
  delivery-status promises, labels, or interface chrome.
- **Governance:** matching palette and linework; an isometric document inspected
  through a magnifying glass, with three linked project-history records below
  it and one amber record accent. No fabricated signatures or test results.
