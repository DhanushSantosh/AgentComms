# Requests for comments

Use an RFC for changes to public contracts, durable schemas, governance,
identity, signing, transactions, installation security, supported platforms,
or major TUI navigation.

Name proposals `NNNN-short-title.md`. Include:

1. Status and owners.
2. Problem and desired outcome.
3. Proposed design.
4. Alternatives considered.
5. Compatibility and rollout.
6. Security and privacy implications.
7. Test and rollout plan.
8. Unresolved questions.

Implementation begins after the RFC is accepted in review.
