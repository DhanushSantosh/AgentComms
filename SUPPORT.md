# Support

Use GitHub Issues for reproducible bugs and feature proposals. Include the Agent Comms version, operating system, `doctor --json` output with sensitive paths redacted, and exact reproduction steps. Security reports belong in private security advisories.

Open-ended product ideas and community questions belong in GitHub Discussions when enabled. Maintainers do not automatically close accepted bugs, roadmap work, security work, or accessibility issues solely because they are old.

Official platform and version support is defined in [development workflow](docs/development-workflow.md) and [release process](docs/releasing.md). External contributors are not required to use Agent Comms to contribute.
